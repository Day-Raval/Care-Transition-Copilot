# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project respectful, inclusive, and free
from harassment.

## Expected Behavior

- Use welcoming and respectful language.
- Accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- Be careful and humble when discussing healthcare, safety, privacy, and model
  limitations.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without explicit permission.
- Introducing real patient data, PHI, secrets, or credentials into the project.
- Misrepresenting demo software as clinically validated or production-ready.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or other
contributions that violate this code of conduct. Serious or repeated violations
may lead to a temporary or permanent ban from project spaces.
