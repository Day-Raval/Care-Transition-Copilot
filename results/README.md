# Results Folder Guide

`results` is grouped by the kind of artifact:

- `modeling/` - model training, comparison, fairness, and narrative result files.
- `operations/` - API audit logs, served-prediction drift logs, and stream-processing state.
- `care_delivery/` - generated care plans, clinician decisions, notification outcomes, and local FHIR write-back stubs.

Generated mock transition reports live in `reports/` because they are user-facing demo artifacts.
